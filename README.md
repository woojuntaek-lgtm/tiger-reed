# 호랑이와 갈대

에니어그램 8번 지도자 [Psyche 10] 영상의 부록 앱입니다. 너무 세면 부러진다는 태강즉절(太剛則折)을 몸으로 느끼는 30초 바람 견디기 게임, 친구와 적 사이에 사람을 놓아 보고 한 걸음 물러서는 연습(세 장면 선택, 다섯 장의 카드), 지키는 힘과 누르는 힘의 1분 계기판, 그리고 8번 지도자 한눈에(두려움·바람·방어기제·미덕과 악덕·상징·동양 수리의 반전·날개와 화살표·추정 인물·8번과 잘 지내려면)를 담았습니다. 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

## 구성
- ① 바람 30초: 누르면 휘고 떼면 꼿꼿이 — 볕엔 자라고 센 바람에 버티면 금이 가는 게임
- ② 한 걸음: 친구-중간-적 막대, 그 사람 입장 한 줄, 세 장면 선택, 다섯 장의 카드
- ③ 힘 계기판: 10문항, 지키는 힘 vs 누르는 힘 저울
- ④ 8번 지도자: 한눈에 표, 3·8 나무 반전, 8w9 곰·8w7 독립자, 스트레스 5·통합 2, 추정 인물, 잘 지내려면

## 알림
- 내용은 정필 수심명의 저서·특강·강의원고(영상 대본)를 따랐습니다. 장면 선택의 풀이, 카드 뒷면의 실천, 계기판 문항은 대본을 바탕으로 앱이 만든 것입니다.
- 계기판과 게임은 성찰을 돕는 참고용이며 검사·진단이나 전문 상담을 대신하지 않습니다. 인물은 추정일 뿐입니다.
- 이름이나 적은 말, 고른 답은 저장하거나 보내지 않습니다.
